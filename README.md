# Azure Git Integration (CNS 3205)
* **Cloud VM Provisioning:** Configured an Ubuntu Server instance on Microsoft Azure[cite: 1, 6].
* **User Management:** Created dedicated user accounts and configured administrative privileges using the default `sudo` group[cite: 6, 7].
* **SSH Key Setup:** Set up `rsa-4096` key-based authentication between local workstations, Azure, and GitHub[cite: 4].
* **Shared Bare Repository:** Initialized a central shared bare repository at `/srv/git/demo_admin.git` on the server[cite: 8, 9].
* **CI/CD Automation:** Configured a GitHub Actions pipeline (`.github/workflows/deploy.yml`) to automatically deploy update pushes on the `main` branch[cite: 11, 12].
